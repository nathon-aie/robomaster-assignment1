# Step 5 — Map Planning & A* Autonomous Path Execution

เอกสารและคู่มือระบบสร้างแผนที่จำลอง (Interactive Grid Map) และการคำนวณหาเส้นทางด้วยอัลกอริทึม A* สำหรับ RoboMaster EP ตามข้อกำหนดใน [REQ.md](../REQ.md)

---

## 🎯 วัตถุประสงค์ (Overview)

ระบบใน Step 5 ทำหน้าที่เป็นตัววางแผนเส้นทาง (Path Planner) และแปลงสภาพแวดล้อมสนามจริงให้เป็นชุดคำสั่งการเคลื่อนที่อัตโนมัติ:
1. **Interactive Map GUI**: หน้าต่างโปรแกรม Pygame สำหรับจำลองสนามตาราง Grid (60×60 cm) และวาดแนวกำแพง
2. **A\* Pathfinding Engine**: คำนวณหาเส้นทางที่ดีที่สุดจากจุดเริ่มต้น (Start) ไปยังจุดเป้าหมาย (Goal)
   - **Shortest Path**: ค้นหาเส้นทางที่ระยะทางสั้นที่สุด
   - **Min Turns Path**: ค้นหาเส้นทางที่ลดจำนวนครั้งในการเลี้ยว เพื่อเพิ่มความเร็วและความแม่นยำของหุ่นยนต์
3. **JSON Plan Export**: บันทึกแผนที่และชุดคำสั่งการเคลื่อนที่ลงใน [`data/robot_map_plan.json`](../data/robot_map_plan.json) เพื่อส่งต่อให้ระบบควบคุมหุ่นยนต์ทำงานอัตโนมัติ

---

## 🗺️ การใช้งานโปรแกรม Map Planner GUI

เปิดหน้าต่างโปรแกรมวางแผนที่ด้วยคำสั่ง:
```bash
./run map
```

### คีย์ลัดและการควบคุม (Keybindings & Controls)
| การกระทำ / ปุ่มกด | หน้าที่การทำงาน |
| :--- | :--- |
| **คลิกซ้าย** | เพิ่มหรือลบแนวกำแพงระหว่างช่อง Grid |
| **กด `S` ค้าง + คลิกซ้าย** | วางตำแหน่งจุดเริ่มต้น (Start Point) |
| **กด `G` ค้าง + คลิกซ้าย** | วางตำแหน่งจุดหมายปลายทาง (Goal Point) |
| **`Spacebar`** | สั่งคำนวณเส้นทางที่สั้นที่สุด (Shortest Path) |
| **`T`** | สั่งคำนวณเส้นทางที่เลี้ยวน้อยที่สุด (Min Turns) |
| **`K`** | บันทึกแผนที่และชุดคำสั่งลงไฟล์ `data/robot_map_plan.json` |
| **`L`** | โหลดแผนที่ที่บันทึกไว้กลับขึ้นมาแสดง |
| **`C`** | ล้างแผนที่และเส้นทางทั้งหมด |

## 📄 โครงสร้างไฟล์แผนที่ (`robot_map_plan.json`)

เมื่อกดปุ่ม `K` โปรแกรมจะสร้างไฟล์ JSON ที่มีโครงสร้างดังนี้:

```json
{
  "grid_size": [6, 6],
  "start": [0, 0],
  "goal": [5, 5],
  "walls": [
    [[0, 0], [0, 1]],
    [[1, 1], [1, 2]]
  ],
  "path": [
    [0, 0],
    [1, 0],
    [2, 0],
    [2, 1],
    [2, 2]
  ],
  "commands": [
    "Move Forward: 2 cells",
    "Turn Right (90 deg)",
    "Move Forward: 2 cells"
  ]
}
```

## 🤖 การนำแผนที่ไปสั่งการหุ่นยนต์จริง

เมื่อได้ไฟล์ `data/robot_map_plan.json` แล้ว หุ่นยนต์สามารถโหลดและปฏิบัติภารกิจได้ทันที:

### 1. ทดสอบจำลองในคอมพิวเตอร์ก่อนลงสนาม
```bash
./run sim
```

### 2. สั่งรันบนหุ่นยนต์จริง
```bash
./run run
```

> **ข้อกำหนดการเริ่มต้นในสนามจริง**:
> - วางหุ่นยนต์ที่จุด Start โดยให้**หน้ารถหันตรงไปตามทิศทางเริ่มต้นของเส้นทาง**
> - Thread 1 จะทำการล็อกค่ามุม Heading อัตโนมัติ (`Yaw = 0.0°`) และ Thread 2 จะเริ่มปฏิบัติตามคำสั่งทีละขั้นตอนจนถึงจุดหมาย
