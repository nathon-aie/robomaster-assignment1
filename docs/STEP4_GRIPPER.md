# Step 4 — Gripper Pick & Drop System

เอกสารและคู่มือระบบควบคุมแขนกล (Robotic Arm) และมือจับ (Gripper) สำหรับหุ่นยนต์ RoboMaster EP ตามข้อกำหนดใน [REQ.md](../REQ.md)

---

## 🎯 วัตถุประสงค์ (Overview)

ระบบใน Step 4 รับผิดชอบการจัดการภารกิจขนถ่ายวัตถุแบบครบวงจร:
1. **Pick (คีบวัตถุที่จุดเริ่มต้น)**: เปิดกริปเปอร์ $\rightarrow$ ยื่นแขนกลลงไปจับวัตถุ $\rightarrow$ ปิดกริปเปอร์หนีบแน่น $\rightarrow$ ยกแขนขึ้นเพื่อความปลอดภัยขณะเดินทาง
2. **Follow Map (เดินตามแผนที่)**: ควบคุมการเคลื่อนที่ข้ามช่อง Grid ขนาด 60×60 cm ด้วยระบบ Closed-Loop PID Centering (8 Wall Cases) ไปยังจุดเป้าหมาย (Goal)
3. **Drop (วางวัตถุที่จุดหมาย)**: ยื่นแขนกลลง $\rightarrow$ เปิดกริปเปอร์ปล่อยของ $\rightarrow$ ขับถอยหลังเว้นระยะห่าง $\rightarrow$ หุบแขนกลเก็บเข้าตำแหน่งเดิมอย่างปลอดภัย

## 🦾 ลำดับการทำงานของแขนกล (Action Sequences)

โมดูลหลักได้รับการพัฒนาอยู่ใน [`src/gripper_controller.py`](../src/gripper_controller.py) ในคลาส `SimpleGripperController`:

### 1. ลำดับการคีบ (Pick Sequence)
```text
[1. Open Gripper] ──> [2. Lower & Extend Arm] ──> [3. Close Gripper] ──> [4. Lift Arm] ──> [5. Retract Arm]
```
- **เปิดมือจับ**: สั่ง `gripper.open()` เพื่อเตรียมพร้อมรับวัตถุ
- **ยื่นและลดระดับ**: ขยับแขนกลไปข้างหน้าและกดลงในระดับที่พอดีกับวัตถุ
- **หนีบจับ**: สั่ง `gripper.close()` ด้วยแรงหนีบที่เสถียร
- **ยกและดึงกลับ**: ยกแขนกลขึ้น +20 cm และดึงถอยกลับ -10 cm เพื่อไม่ให้บังเซนเซอร์ ToF ด้านหน้าและไม่ให้ชนขอบกำแพงระหว่างวิ่ง

### 2. ลำดับการวาง (Drop Sequence)
```text
[1. Lower Arm] ──> [2. Open Gripper] ──> [3. Chassis Backup] ──> [4. Lift & Recenter Arm]
```
- **ลดระดับแขนกล**: นำวัตถุลงวางที่พื้นกึ่งกลางช่อง Grid เป้าหมาย
- **ปล่อยวัตถุ**: สั่ง `gripper.open()` เพื่อปล่อยของ
- **ถอยหุ่นยนต์ (Chassis Backup)**: สั่งฐานล้อเคลื่อนที่ถอยหลัง (`x = -0.30 m` หรือระยะที่กำหนด) เพื่อถอยออกจากตัววัตถุโดยไม่ปัดโดน
- **เก็บแขนกล (Recenter)**: สั่ง `arm.recenter()` หุบปากและพับแขนเก็บเข้าตำแหน่งเดิม

## 🚀 วิธีการสั่งรัน (Usage)

### 1. สั่งงานแขนกลและ Gripper โดยตรง (Direct Manual Test)
```bash
# ทดสอบคีบของทันที
./run pick

# ทดสอบวางของทันที (ถอยหุ่น 30 cm)
./run drop
```

### 2. รันโหมดจำลอง (Simulation Pick & Drop)
```bash
# จำลองเต็มรูปแบบ (มีถามยืนยันแต่ละสเต็ป)
./run sim

# จำลองแบบ Auto-confirm ทั้งหมด (ไม่หยุดถาม)
./run sim -y

# จำลองเฉพาะการเดินตามแผนที่ (ข้าม Pick และ Drop)
./run sim --skip-pick --skip-drop -y
```

### 3. รันบนหุ่นยนต์จริงเต็มรูปแบบ (Autonomous Mission)
```bash
# รันภารกิจเต็มรูปแบบ: คีบ -> เดินตามแผนที่ด้วย PID -> วางของ
./run run

# ปรับระยะยกแขนหรือระยะถอยหุ่นยนต์ตอนวาง
./run run --extend-cm 7.0 --lift-cm 10.0 --backward-cm 30
```

## ⚙️ พารามิเตอร์และ CLI Arguments

| ตัวเลือก CLI | ค่าเริ่มต้น | รายละเอียด |
| :--- | :--- | :--- |
| `--extend-cm` | `7.0` | ระยะยื่นแขนกลไปข้างหน้าขณะหยิบของ (cm) |
| `--lift-cm` | `10.0` | ระยะยกแขนกลขึ้นหลังจับของเสร็จ (cm) |
| `--backward-cm` | `30.0` | ระยะถอยหลังของฐานล้อขณะวางของ (cm) |
| `--skip-pick` | `False` | ข้ามขั้นตอนคีบตอนเริ่มต้น (เริ่มเดินตามแผนที่ทันที) |
| `--skip-drop` | `False` | ข้ามขั้นตอนวางของตอนถึงจุดหมาย |
| `-y`, `--yes` | `False` | ยืนยันคำถามทุกขั้นตอนอัตโนมัติ (Auto-confirm) |
