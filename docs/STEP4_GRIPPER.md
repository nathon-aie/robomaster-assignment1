# Step 4 — Gripper Pick & Drop Placement System

คู่มือและเอกสารอธิบายระบบ **แขนกลและกริปเปอร์ (Robotic Arm & Gripper)** สำหรับการหยิบวัตถุที่จุดเริ่มต้น (Pick) และการวางวัตถุที่จุดเป้าหมาย (Drop) อย่างแม่นยำตามข้อกำหนดใน [REQ.md](../REQ.md)

---

## 🎯 วัตถุประสงค์ (Step 4 Requirements)

1. **ลำดับการหยิบของที่จุด Start (Pick Sequence)**:
   - อ้ากริปเปอร์ $\rightarrow$ ยื่นแขนไปข้างหน้า $\rightarrow$ ลดระดับแขนลง $\rightarrow$ ปิดกริปเปอร์หนีบวัตถุ $\rightarrow$ ยกแขนขึ้นเพื่อความปลอดภัยขณะเดินทาง
2. **การปรับตำแหน่งกึ่งกลางก่อนวางของ (Centering Alignment before Drop)**:
   - นำสถานะเซนเซอร์ Sharp (L/R) และ ToF จาก Thread 1 มาตรวจสอบกำแพงทั้ง 8 Cases เพื่อปรับหุ่นยนต์ให้อยู่กึ่งกลางช่อง Grid ก่อนเริ่มปล่อยของ
3. **ลำดับการวางของที่จุด Goal (Drop Sequence)**:
   - ปรับระยะถอยของตัวหุ่น (Chassis Offset) $\rightarrow$ วางแขนลง $\rightarrow$ อ้ากริปเปอร์ปล่อยวัตถุ $\rightarrow$ ยกแขนขึ้น $\rightarrow$ ดึงแขนกลับและหุบกริปเปอร์ (`recenter`)
4. **ความปลอดภัยและการยืนยัน (Safety & Simulation Confirmation)**:
   - รองรับโหมด Interactive Prompt (กด Enter เพื่อยืนยันแต่ละขั้นตอน) หรือรันแบบอัตโนมัติด้วย Flag `-y` / `--yes`
   - สามารถเลือกข้ามขั้นตอนหนีบหรือวางของได้ (`--skip-pick`, `--skip-drop`) เพื่อทดสอบเฉพาะระบบการเดิน

## 📊 ตารางการตรวจสอบตำแหน่งกำแพงก่อนวางของ (8 Wall Cases)

ก่อนที่หุ่นยนต์จะสั่งปล่อยวัตถุ ระบบจะอ่านค่าจาก Thread 1 (`SensorHub`) เพื่อตรวจสอบว่าหุ่นยนต์อยู่ตรงกลางจุดเป้าหมาย:

| สภาพแวดล้อม | ตรวจสอบด้านหน้า (ToF) | ตรวจสอบด้านข้าง (Sharp L/R) | การปรับระยะก่อนวาง |
| :--- | :--- | :--- | :--- |
| **มีกำแพงหน้า + กำแพง 2 ข้าง** | ToF วัดระยะห่างจากกำแพงหน้า | $\|\text{Sharp}_L - \text{Sharp}_R\| < 2\text{ cm}$ | ปรับกึ่งกลาง $v_y$ จนบาลานซ์ทั้งสองฝั่ง |
| **มีกำแพงหน้า + กำแพงซ้าย** | ToF วัดระยะห่างจากกำแพงหน้า | $\text{Sharp}_L \pm 2\text{ cm}$ จาก Nominal | ปรับ $v_y$ เทียบระยะกำแพงซ้าย $140\text{ mm}$ |
| **มีกำแพงหน้า + กำแพงขวา** | ToF วัดระยะห่างจากกำแพงหน้า | $\text{Sharp}_R \pm 2\text{ cm}$ จาก Nominal | ปรับ $v_y$ เทียบระยะกำแพงขวา $140\text{ mm}$ |
| **มีกำแพงหน้า + ไม่มีกำแพงข้าง** | ToF วัดระยะห่างจากกำแพงหน้า | - | ล็อก Heading ด้วย IMU และหยุดที่ระยะ ToF เป้าหมาย |
| **ไม่มีกำแพงหน้า + กำแพง 2 ข้าง**| - | $\|\text{Sharp}_L - \text{Sharp}_R\| < 2\text{ cm}$ | ปรับกึ่งกลาง $v_y$ จนบาลานซ์ทั้งสองฝั่ง |
| **ไม่มีกำแพงหน้า + กำแพงซ้าย** | - | $\text{Sharp}_L \pm 2\text{ cm}$ จาก Nominal | ปรับ $v_y$ เทียบระยะกำแพงซ้าย $140\text{ mm}$ |
| **ไม่มีกำแพงหน้า + กำแพงขวา** | - | $\text{Sharp}_R \pm 2\text{ cm}$ จาก Nominal | ปรับ $v_y$ เทียบระยะกำแพงขวา $140\text{ mm}$ |
| **ไม่มีกำแพงหน้า + ไม่มีกำแพงข้าง**| - | - | ใช้พิกัด Grid Odometry $(pos\_x, pos\_y)$ จากจุด Start |

## 🚀 คำสั่งสำหรับทดสอบและใช้งาน (Usage Guide)

### 1. รันการทำงานแบบครบวงจร (Pick $\rightarrow$ เดินตามแผนที่ $\rightarrow$ Drop)
```cmd
# รันหุ่นยนต์จริงผ่าน Wi-Fi AP (มีถามยืนยันก่อน Pick และ Drop เพื่อความปลอดภัย)
python main.py run --plan data\robot_map_plan.json

# รันแบบอัตโนมัติต่อเนื่องโดยไม่ต้องกดยืนยัน (-y)
python main.py run --plan data\robot_map_plan.json -y
```

### 2. ทดสอบในโหมดจำลอง (Simulation / Dry-Run)
ทดสอบตรรกะการเรียกใช้ Pick และ Drop โดยไม่ต้องต่อฮาร์ดแวร์จริง:
```cmd
# จำลองการทำงานเต็มรูปแบบ
python main.py simulate --plan data\robot_map_plan.json -y
```

### 3. รันแบบข้ามขั้นตอน Pick หรือ Drop (เฉพาะทดสอบการเดิน)
```cmd
# ข้ามเฉพาะขั้นตอนหนีบของที่จุดเริ่มต้น
python main.py run --plan data\robot_map_plan.json --skip-pick

# ข้ามทั้ง Pick และ Drop เพื่อทดสอบเฉพาะการเดินตามแผนที่
python main.py run --plan data\robot_map_plan.json --skip-pick --skip-drop -y
```
